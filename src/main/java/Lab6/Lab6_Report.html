Lab 6 Project Report

Project Overview

This project extends the foundational binary tree structure defined in Tree2.java to implement complex algorithms including tree analytics, expression parsing, and Huffman coding.

NOTE: The 'Tree2.java' and the class 'Node2' is the renamed version of the original 'Tree.java'; the new 'Tree.java' and 'Node.java' are the separated classes from the original 'TreeApp.java'; the reason I renamed and separated them is to prevent package and class conflictions in 'Lab6' folder.

1. Problem1234.java: Tree Analytics

Focuses on recursive properties of binary trees. It provides essential metrics for evaluating tree structures.

Core Algorithms:
  • Node Counting: Recursive traversal to sum all non-null nodes.
  • Height Calculation: Determines the maximum depth of the tree (leaf = 0).
  • Balance Detection: Checks if the absolute difference in height between left and right subtrees is ≤ 1 across all nodes.
  • Identity Verification: Deep comparison of two trees to ensure structural and value equality.

2. Section7_8.java: Expression Trees & Prefix Conversion

Handles the transformation between arithmetic expression trees and Prefix (Polish) notation.

Design Strategy:
  • Prefix Conversion: Uses recursion to traverse the tree (Operator -> Left -> Right) and push values/operators onto a global stack.
  • Tree Reconstruction: Rebuilds the binary tree from a stack-based prefix expression. It utilizes type detection (instanceof) to distinguish between operands (Integers) and operators (Characters).

3. Huffman.java: Data Compression Algorithm

Implements the Huffman coding algorithm for optimal prefix-free data encoding based on character frequency.

Huffman Workflow:
  • Frequency Mapping: Scans the input message to create a dictionary of character counts, sorted in ascending order.
  • Priority Queue Construction: Utilizes a PriorityQueue (Min-Heap behavior) to store nodes ordered by their frequency value.
  • Tree Building: Repeatedly extracts the two nodes with the lowest frequency, combines them into a parent node (sum of frequencies), and re-inserts the parent into the queue until only the root remains.
  • Encoding: Generates unique binary paths for each character, ensuring high-frequency symbols have shorter paths.

Design Principles & Architecture

  • Inheritance: All three modules extend Tree2, leveraging its base methods for node creation and printing while specializing functionality.
  • Recursion: The project heavily relies on recursive design patterns, which is the most natural approach for hierarchical data structures like binary trees.
  • Polymorphism in Nodes: The Node2 class is designed to hold either numerical values or operator characters, managed through type-specific node constructors.
  • Conflict Management: The renaming and separation of classes (as noted in the project setup) ensures modularity and prevents namespace collisions within the Lab6 package.

Conclusion

The Lab 6 package demonstrates a comprehensive understanding of binary trees, from simple structural analysis to complex real-world applications like expression parsing and lossless data compression. The modular design allows for easy extension and testing of individual algorithms.
